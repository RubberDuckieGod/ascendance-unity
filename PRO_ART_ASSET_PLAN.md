# Ascendance 0.6.0 — Professional Art Plan

The previous free/CC0 art route does **not** meet the requested Baldur's Gate-like visual target. 0.6.0 therefore stops auto-downloading stylized packs and becomes a bridge for licensed, production-quality Unity assets.

## Recommended environment

**DETAILED - Medieval Village — Astrofish Games**
- Current Unity Asset Store package targets Unity 6 URP.
- Realistic medieval architecture rather than low-poly prototype art.
- Import the package into this project, then use **Ascendance > Professional Art > Map Imported AAA Assets...** and drag building/prop prefabs into the Stonebrook slots.

## Recommended characters

**Medieval Characters Pack — Alesky**
- Rigged PBR medieval characters with 4K maps and Humanoid rigs.
- Good starting source for Aldric / Rowan / enemy-quality human silhouettes.

**RPG Character Creation Pack — Lylek Games** is an alternate modular character source if more customization is preferred.

## Important licensing note

Unity Asset Store packages cannot be redistributed inside this ChatGPT-produced ZIP. They must be acquired/imported under your own Unity Asset Store license. The mapper creates local wrapper prefabs referencing those imported assets; it does not copy the marketplace package out of your project.

## Mapping workflow

1. Import the licensed environment and character packages through Unity Package Manager / My Assets.
2. Open **Ascendance > Professional Art > Map Imported AAA Assets...**.
3. Drag character and environment prefabs into the matching slots.
4. Click **INSTALL MAPPED ART INTO ASCENDANCE**.
5. Press Play. The RealArt resource slots outrank all old 0.5.x prototype art.
