ASCENDANCE EQUIPMENT VISUAL PREFABS

CharacterPresentationController exposes AttachEquipmentResource(resourceName, slot).
Place equipment prefabs in this folder and attach them to standardized slots:
  RightHand / weapon
  LeftHand / offhand
  Back
  Hip
  Staff
  Bow

EquipmentSocketRig discovers common bone/socket names automatically and creates safe fallback sockets when necessary.
